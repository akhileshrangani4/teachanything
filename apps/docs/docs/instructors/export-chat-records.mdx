When you want to keep student conversations, analyze them, or share them with a co-instructor or for research, you can export them from the dashboard. Everything downloads to your computer as a single `.zip` file — no student ever sees the export.

## How to export

<Steps>
  <Step title="Open the Student Chats tab">
    Go to your chatbot and open **Student Chats**, the same place you [review
    conversations](/instructors/review-conversations).
  </Step>
  <Step title="Choose what to export">
    Use **Export all** to download every conversation, or tick the checkboxes
    next to specific chats and use **Export selected**.
  </Step>
  <Step title="Pick your formats">
    A short dialog lets you choose any combination of the formats below. A
    README explaining each file is always included.
  </Step>
  <Step title="Download the bundle">
    Everything arrives as one `.zip`. Unzip it and open whichever file suits
    what you're doing.
  </Step>
</Steps>

## The formats

<CardGroup cols={3}>
  <Card title="Visual transcript (HTML)" icon="globe">
    Double-click to open in any web browser. A searchable, clickable copy of the
    dashboard: a list of conversations on the left, the full chat on the right.
  </Card>
  <Card title="Spreadsheet (CSV)" icon="table">
    Opens in Excel or Google Sheets. One row per message, with columns for the
    conversation, turn, role, timestamp, message, sources, and study tools —
    ready for sorting and analysis.
  </Card>
  <Card title="Plain text (TXT)" icon="file-text">
    A portable transcript grouped by conversation. Opens anywhere, keeps nothing
    but the words.
  </Card>
</CardGroup>

:::tip[Which one should I use?]
Open the **HTML** file to read through chats comfortably, use the **CSV** for
counting and filtering across many students, and keep the **plain text** for
long-term archives or pasting into other tools.
:::

## What's included

<CardGroup cols={2}>
  <Card title="The full conversation" icon="messages-square">
    Every student question and the assistant's reply, in order, with timestamps.
  </Card>
  <Card title="The sources cited" icon="quote">
    Which of your materials the assistant drew on for each answer.
  </Card>
  <Card title="Quizzes and study tools" icon="list-checks">
    Any interactive quiz a student was given, with the questions, the correct
    answers, and what the student chose on each attempt — plus their score.
  </Card>
  <Card title="A README" icon="info">
    A short guide describing exactly which files are in the bundle and how to
    open each one.
  </Card>
</CardGroup>

## The visual (HTML) export

The HTML file is the easiest way to read an export. It looks and works like the
Student Chats dashboard:

<Steps>
  <Step title="Search">
    Type in the search box to filter conversations by anything a student or the
    assistant said.
  </Step>
  <Step title="Click to open">
    Select a conversation to read the full exchange, styled just like the app.
  </Step>
  <Step title="Review quiz answers">
    Quiz turns show the answer key alongside each of the student's attempts, so
    you can see what they got right and where they struggled.
  </Step>
</Steps>

It's a single self-contained file: no internet connection is needed to open it,
and nothing is uploaded anywhere.

## A note on student privacy

Exports contain the same anonymized conversations you see in the dashboard.
Once a file is on your computer it's outside Teach Anything, so store and share
it with the same care you'd give any student record, and follow your
institution's privacy policies — especially for anything used in research.
